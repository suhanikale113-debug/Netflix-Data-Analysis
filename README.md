# 🎬 Netflix Data Analysis

## 📌 Project Overview

This project analyzes a Netflix dataset using Python to understand content distribution, country-wise patterns, and release-year trends.

The project focuses on data cleaning, exploratory data analysis, and visualization to extract meaningful insights from Netflix content data.

## 🎯 Objectives

- Clean and prepare the Netflix dataset for analysis
- Analyze the distribution of Movies and TV Shows
- Identify countries with the highest number of Netflix titles
- Analyze content trends based on release year
- Present insights using charts and visualizations

## 📊 Tasks Completed

### 1. Netflix Data Cleaning & Preparation
- Loaded the Netflix dataset using Pandas
- Checked missing values and duplicate records
- Handled inconsistent values
- Standardized important columns
- Prepared a cleaned dataset for analysis

### 2. Content Type Analysis
- Analyzed Movies and TV Shows
- Calculated the number and percentage of each content type
- Created visualizations to compare content distribution

### 3. Country-Wise Netflix Content Analysis
- Cleaned and processed country information
- Analyzed the number of titles available by country
- Identified the top content-producing countries
- Created country-wise visualizations

### 4. Trend Analysis by Release Year
- Analyzed Netflix titles based on release year
- Identified growth and decline trends
- Compared Movies and TV Shows over time
- Created release-year trend visualizations

## 🛠️ Technologies & Skills Used

- Python

- Seaborn
- Jupyter Notebook
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Trend Analysis

## 📈 Key Findings

- Movies represent a larger portion of the dataset than TV Shows.
- The United States has the highest number of titles in the country-wise analysis.
- India and the United Kingdom are also major contributors to the dataset.
- The number of titles increased significantly during the 2010s.
- The dataset contains the highest number of titles released in 2018.
